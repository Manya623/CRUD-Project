# Student Management System (CRUD Application)

A simple CRUD (Create, Read, Update, Delete) web application built using HTML, CSS, PHP, and MySQL. This project allows users to manage student records by adding, viewing, updating, and deleting data stored in a MySQL database.

## Features
- Add Student
- View Students
- Update Student Details
- Delete Student Records

## Tech Stack
- HTML5
- CSS3
- PHP
- MySQL
- XAMPP

## Project Structure
text
crud_project/
├── index.php

## Database
Create a database named `student_db` and a table named `students`.

## Run the Project
1. Clone the repository.
2. Move the project to the `htdocs` folder in XAMPP.
3. Start Apache and MySQL.
4. Import the database.
5. Open `http://localhost/crud_project` in your browser.
